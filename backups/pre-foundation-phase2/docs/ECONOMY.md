# Economy

Prices are configurable in `data/economy.json`. They are illustrative game values from the project brief, not verified national averages.

Oil-change example:

- Customer charge: $55.00
- Parts: $22.00
- Supplies: $1.50
- Net to the shop: $31.50
- Starting cash: $750.00

The completion screen shows revenue minus cost. That is the whole point of this first job.
